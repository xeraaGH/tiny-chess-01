A chess engine in at most 4,096 bytes of Python: 0x88 board, negamax alpha-beta with a transposition table, quiescence on captures, MVV-LVA and killer move ordering, and a tapered piece-square evaluation with bishop-pair and passed-pawn terms. It searches to a fixed node budget per move, so every trial replays deterministically.

## Run it

```sh
python3 main.py
```
